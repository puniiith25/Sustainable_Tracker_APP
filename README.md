# 🌱 Sustainable Tracker App

The **Sustainable Tracker App** is a mobile application designed to help users make **eco-friendly purchasing decisions** by tracking and visualizing **CO₂ emissions** associated with products and user activities.  
The app encourages sustainable living through awareness, tracking, and progress visualization.

---

## 🚀 Features

- 🔐 User Authentication (Login / Signup)
- 🛒 Sustainable product tracking
- 🌍 CO₂ emission calculation and visualization
- 📊 Monthly savings charts
- 🏆 Badges & achievements for sustainability milestones
- 📱 Clean and responsive Flutter UI
- 🔒 Secure token-based authentication
- ☁️ MongoDB cloud database support

---

## 🛠 Tech Stack

### Frontend (Mobile App)
- **Flutter**
- **Dart**
- **Font Awesome Icons**


### Backend
- **Node.js**
- **Express.js**
- **MongoDB (Atlas)**
- **JWT Authentication**
- **Cookie-based Auth**
- **Helmet & CORS for security**

## ⚙️ Installation & Setup

### 🔹 Clone the Repository
```
bash
git clone https://github.com/puniiith25/Sustainable_Tracker_APP.git
cd Sustainable_Tracker_APP

```
### Backend Setup
```
cd backend
npm install
```
## .env file 
```
PORT=4000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_ORIGIN=http://localhost:3000
```
## Start backend server
```
npm run server
```

### Frontend Setup (Flutter)
```
cd frontend
flutter pub get
flutter run
```
